# CJR AI Chatbot

> ** v2.0.0 Released!** Complete refactor with production-ready code, comprehensive security, and WordPress.org compliance.

An AI-powered WordPress chatbot plugin that uses vector embeddings and semantic search to answer questions based on your site content and custom Q&A.

##  What's New in v2.0

This version represents a **complete refactor** from the ground up:

-  **Fixed Critical Bugs** - Resolved API parsing issues that prevented the chatbot from working
-  **Production-Ready Security** - Rate limiting, CSRF protection, input sanitization
-  **Clean Architecture** - Modular class-based structure following WordPress standards
-  **Professional UI/UX** - Modern chat widget, comprehensive admin interface
-  **WordPress.org Ready** - Follows all coding standards and best practices
-  **Well Documented** - Inline comments, setup guide, WordPress.org readme

[See CHANGELOG.md for detailed changes]

##  Features

- AI-powered responses using OpenAI-compatible APIs (RouteLLM, OpenAI)
- Semantic search with vector embeddings
- Custom Q&A management
- Comprehensive security (rate limiting, nonce verification)
- Batch processing for large sites
- Modern, responsive chat widget
- Internationalization ready

##  Tech Stack

- **Backend:** PHP 7.4+, WordPress 5.8+
- **Frontend:** Vanilla JavaScript, CSS3
- **AI/ML:** OpenAI API, Vector Embeddings
- **Architecture:** OOP, REST API, AJAX
- **Security:** Rate Limiting, CSRF Protection, Input Validation
